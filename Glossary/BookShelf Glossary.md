# BookShelf Glossary

- **Book** — запис про книгу; див. [[Book]].
- **Reading Status** — стан читання; див. [[Reading Status]].
- **CRUD** — створення, читання, оновлення, видалення.
- **Vault** — папка нотаток Obsidian.
- **MCP** — Model Context Protocol, протокол інтеграції інструментів з агентом.
- **Agent Harness** — інфраструктура контрольованої роботи агента; див. [[Agent Harness]].
