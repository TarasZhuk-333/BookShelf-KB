# SQLite Storage

Локальна база даних SQLite з таблицею `books`.

Основні операції: створення, читання, оновлення та видалення записів [[Book]].

Валідація значень [[Reading Status]] виконується на рівні застосунку; за потреби — обмеженням у схемі БД.

Див. [[ADR-001 Technology Stack]].
